    FAQ
    Kenapa top up lambat masuk?
    Semua top up di-ACC MANUAL oleh OWNER. Tidak ada auto-ACC. Ini untuk keamanan agar tidak ada user yang klaim transfer tanpa bayar.
    Kenapa tidak bisa beli module
    Kamu WAJIB top up pertama minimal Rp 5.000 dulu.
    Bagaimana cara harga turun?
    Klaim Voucher Harian atau masukan kode voucher di menu VOUCHER.
    Bagaimana cara kerja control module?
    Setiap kali module .sh dijalankan, device otomatis terdaftar di sistem. Owner dapat memantau dan mengirim perintah RESET/STOP/NOTIFY serta memblokir device kapan saja.
    Bagaimana USER ONLINE bekerja?
    User Online menampilkan user yang sedang membuka & login di website (real-time, bukan simulasi). Cek di menu PUSAT INFORMASI (Lonceng).
